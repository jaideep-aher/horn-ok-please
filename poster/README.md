# Expo poster: Horn OK Please (24 × 24 in)

## Printed expo poster (Data+ v3.1)

The printed expo poster (24 × 24 in, Data+ layout, v3.1) is `poster/dataplus/print-v3.1/horn-ok-please-poster.pdf` (sha256 `f54b9285ed87107da2778b028c98713918aea2d40c87b425d9282d396acf8024`). Rebuild it with `poster/dataplus/build.sh`. The square poster in `poster/` is the earlier version.

`horn-ok-please.pdf` is the print file: 24 × 24 in, fonts embedded, images at 300 ppi or more, 0.5 in clear margin. Print it at 100% (no "fit to page").
Previews: `build/horn-ok-please-poster-full-300dpi.png` (full size) and `build/horn-ok-please-letter-proof.png` (8.5 × 11 in proof at 33%).

| File | What it is |
|---|---|
| `poster.html` | Poster source (HTML/CSS, `@page` 24in × 24in), printed with headless Chrome |
| `assets/` | Hero tiles, occlusion heatmap, blurred truck photo, QR code, and the static fonts (Lato, Alfa Slab One, Noto Sans Devanagari; SIL OFL 1.1, notices in `assets/fonts/`) |
| `NUMBERS.md` | Provenance: every printed number, its result file and field |
| `derived_stats.py` → `build/derived_stats.json` | CIs and exact McNemar p-values computed from committed result files with `hornok.metrics`. Printed CIs are rounded outward. |
| `TALK_SCRIPT.md`, `make_talk_script.py` | Timed expo walkthrough (under 4:30 at 140 wpm), elevator version, Q&A |
| `RUBRIC_MAP.md` | Poster rubric criteria → poster elements and script lines |
| `build.sh` | Renders `poster.html` → `horn-ok-please.pdf` and prints a layout/overflow report |
| `verify.py`, `fontmap.py` → `build/verify_report.txt`, `build/fontmap.txt` | Print checks: page box, min font size, margin, QR decode; per-element font sizes |
| `make_proof.py` | Letter-size proof PNG |
| `make_assets.py` | Regenerates `assets/` from the XAI stimuli. The truck photo defaults to `assets/truck_tailgate_blurred.jpg` |
| `measure_nat.sh` | Natural (unstretched) panel heights, for reflowing text |

## Rebuild

Needs Google Chrome or Chromium (set `CHROME=` if it isn't `google-chrome`), poppler-utils (`pdftoppm`, `pdfinfo`, `pdffonts`, `pdfimages`) and Python 3.11+.

```bash
pip install -r poster/requirements-poster.txt
pip install -e .                      # for hornok.metrics (derived_stats.py only)
python poster/derived_stats.py        # needs eval/gemini_remote/results/*; see NUMBERS.md
poster/build.sh                       # -> poster/horn-ok-please.pdf; "inner scrollH" must equal "clientH"
pdftoppm -r 300 -png -singlefile poster/build/horn-ok-please-poster.pdf poster/build/horn-ok-please-poster-full-300dpi
python poster/make_proof.py
python poster/verify.py && python poster/fontmap.py
pdfinfo -box poster/horn-ok-please.pdf; pdffonts poster/horn-ok-please.pdf; pdfimages -list poster/horn-ok-please.pdf
python poster/make_talk_script.py     # rewrites poster/TALK_SCRIPT.md and prints word counts
```

`make_assets.py` is only needed if a tile or the photo changes. It reads `eval/xai/stimuli/{clean,paint,inpaint}/` (generated by `eval/xai/build_stimuli.py`; override with `HORNOK_STIMULI`). The truck photo defaults to the committed blurred file `assets/truck_tailgate_blurred.jpg`. Set `HORNOK_PHOTO` to a source image to rebuild that blur (whole-frame blur, then pixelate the painted plate). The script does not open an unblurred original unless that path is passed as `HORNOK_PHOTO`. Only blurred truck photos may appear on the poster.

`poster/publish.py`, `publish_round2.py`, and `publish_round3.py` still overwrite `poster.html` and `horn-ok-please.pdf` from older eval summaries. Do not run them to refresh this poster.

## Rules for editing
- Every number must come from a committed result file and be listed in `NUMBERS.md`. Never type a number that isn't in a result file.
- Body text, every gate-table cell and the findings text are at least 24 pt. Nothing on the poster is under 18 pt; 18–22 pt is only for captions, labels, references and credits. Check with `fontmap.py`.
- After `build.sh`, `inner scrollH` must equal `clientH`. If not, text is clipped; reflow it with `measure_nat.sh`.
