What this is not

Not a crash risk. Not a road test. Not a claim about a frontier API model. IDD, RoadscapesQA, and Bharat Scene Text are not in this run.

A flip, if one is reported, is a change from STOP to GO on these frames. It is not a measured collision.

The dev drawings are new. An empty lane has no vehicle. A shoulder scene parks a truck off the lane. Neither is a locked test frame.
